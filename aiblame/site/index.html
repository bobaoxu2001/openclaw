    How it's measured

    aiblame lists every text file at HEAD, skipping lockfiles, vendored and generated code. It runs git blame -w on each line and classifies the commit that wrote it. Co-author trailers, bot accounts and agent footers mark a commit as AI-written. Repos above 4,000 files are sampled; those numbers carry a ~ and a 95% margin of error.

    Why the numbers are low

    Only disclosed AI work counts. An agent run locally with its co-author trailer turned off, or code typed with autocomplete, leaves no trace in git. A repo can lean heavily on AI and still score near zero here. The ranking rewards disclosure as much as usage.

    Measure your own repo
